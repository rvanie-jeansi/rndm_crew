# PLAN — RANDOM: приложение случайных приключений

Статусы: ⬜ не начато · 🔄 в работе · ✅ готово

## 1. Продукт
Мобильное приложение (Android + iOS через Expo Go). Пользователь жмёт «Мне скучно» → выбирает время (30м / 1ч / 2ч / весь день) и бюджет (0–500 / 500–1500 / 1500+) → получает случайное приключение из цепочки заданий (прогулка по GPS, сфотографировать здание, кафе, кубик за направление) → выполняет → получает опыт, уровни, достижения. Всё отображается на карте и в профиле.

**MVP**: онбординг, профиль, генератор, экран приключения, карта, опыт/уровни/достижения, статистика.
**Потом (Этап 8)**: бэкенд, друзья, совместные приключения — только если хватит времени.

## 4. Модель данных
```ts
Profile      { name, emoji, interests[], createdAt }
Task         { id, type, title, description?, distanceMeters?, xp,
               location?{lat,lng}, placeType?, status:'pending'|'done', doneAt?, order }
Adventure    { id, title, emoji, timeBudget, moneyBudget, tasks[],
               status:'active'|'completed'|'skipped', createdAt, completedAt?,
               totalDistanceMeters }
VisitedPlace { id, lat, lng, name?, visitedAt, adventureId? }
Stats        { totalAdventures, completedAdventures, totalDistanceMeters,
               totalPlacesVisited, totalTasksDone, xp }
```
`TaskType`: `walk` | `find_place` | `photo` | `visit_cafe` | `roll_dice` | `question`.

Храним в AsyncStorage по ключам `random.profile`, `random.adventures`, `random.visitedPlaces`, `random.stats` (версия ключа — на случай миграций).

## 5. Движок сценариев (ядро)
**Шаблоны (6 штук, MVP):**
1. **Исследователь** 🗺 — пройти 1.5–3 км, найти необычное здание → фото, случайное кафе (если бюджет ≥ среднего), кубик за направление
2. **Авантюрист** 🎲 — 3 броска кубика направлений, пройти их сумму, отметить новое место
3. **Фотограф** 📸 — 3 фото-задания (здание / природа / «живое существо»), прогулка между ними
4. **Гурман** ☕ — (нужен бюджет ≥ среднего) кафе: попробовать то, что не заказывал, отметить место
5. **Ходок** 🚶 — чистая дистанция от времени: N км + контрольная точка
6. **Скавенджер** 🔎 — найти N ориентиров (дом необычного цвета, вывеска с животным, место с видом…)

**Маппинг время→дистанция:** 30м→1–2 км · 1ч→2–4 км · 2ч→4–7 км · весь день→8+ км и больше заданий.
**Бюджет** регулирует состав: `low` — бесплатно (прогулка/кубик), `mid` — можно напиток в кафе, `high` — «угостить себя» / квест-ориентир.

**Алгоритм `generateAdventure({time, money, interests, doneCount})`:**
1. Отфильтровать шаблоны по совместимости с time+money
2. Вес = случайный + `×2.5` если совпадает с интересом пользователя; исключаем последний шаблон (не повторяться)
3. Взвешенный случайный выбор
4. Вызвать функцию шаблона → массив задач с реальными дистанциями и точками (точки — случайные в 0.5–1.5 км вокруг пользователя, `utils/geo.ts`)
5. Собрать `Adventure`, `xp = Σ задач`, сохранить

Погода — заглушка в MVP (просто учитывается как «сценарии следующий раз»).

## 6. Опыт, уровни, достижения
- XP за задание: 10 базовое, 20 с фото, 25 кафе; за дистанцию: `метры/100 × 5`
- Уровень: `нужноXP = 100 × level` (level 1→100, 2→200, …)
- Достижения (8): «Первое задание», «Первое приключение», «Исследователь» (10 мест), «Авантюрист» (20 заданий), «Ходок» (20 км суммарно), «Кофеман» (3 кафе), «Чистовик» (приключение без пропусков), «5 приключений»
- Проверка условий — в единой функции при каждом обновлении Stats

## 7. Карта
- Запрос разрешения `expo-location` → позиция (голубой маркер, слежение)
- Маркеры: цели текущего приключения, посещённые места (серые), позиция пользователя
- Линия маршрута (прозрачный полигон поверх точек)
- «Я здесь» — записать точку в `VisitedPlace`
- В Expo Go работает без ключей (для сборки в сторах позже нужен Google Maps API key)
