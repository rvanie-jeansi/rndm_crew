# Как запустить этот проект с нуля (инструкция для чайников)

Главная цель — запустить это приложение на своём телефоне за 5-10 минут.

## Шаг 1. Установить Node.js

1. Перейди на сайт [nodejs.org](https://nodejs.org)
2. Скачай **LTS** версию (она самая надёжная, зелёная кнопка)
3. Установи её как обычно, просто жми "Далее" во всех окнах

## Шаг 2. Открыть папку проекта в терминале

У нас уже есть папка `rndm_crew`. Надо открыть в ней терминал.

1. Открой папку `C:\Users\DMITRIY\Desktop\rndm_crew` в проводнике
2. Зажми `Shift` на клавиатуре и кликни правой кнопкой мыши по пустому месту внутри папки
3. В появившемся меню выбери `Открыть в Терминале`

Откроется чёрное/серое окошко с текстом.

## Шаг 3. Скопировать файл .env

В этой папке есть файл `.env.example`. Чтобы приложение работало, нужен файл `.env`.

В том же терминале напиши вот это и нажми `Enter`:

```powershell
copy .env.example .env
```

Если файла `.env` уже есть — ничего страшного, просто появится сообщение, что он уже существует. Можешь смело пропустить этот шаг.

## Шаг 4. Скачать все нужные библиотеки

Сейчас нужно скачать кучу файлов, без которых проект не запустится. На это уйдёт 5-10 минут, зависит от интернета.

В терминале напиши:

```powershell
npm install
```

Жди, пока не появится новая строчка и терминал снова не даст вводить команды.

## Шаг 5. Запустить проект

Когда установка закончилась, напиши:

```powershell
npx expo start
```

Через пару секунд в терминале появится огромный QR-код.

## Шаг 6. Открыть на телефоне

1. Установи приложение **Expo Go** на телефон
   - Android: [Google Play — Expo Go](https://play.google.com/store/apps/details?id=host.exp.exponent)
   - iOS: [App Store — Expo Go](https://apps.apple.com/ru/app/expo-go/id982107779)

2. Открой Expo Go
3. Нажми `Сканировать QR-код` (Scan QR Code)
4. Наведи камеру на QR-код в терминале
5. Приложение само откроется

Всё. Готово.

## Если что-то пошло не так

- **Терминал завис и ничего не происходит** — просто подожди. `npm install` всегда долго грузит первый раз.
- **Появилась ошибка при `npm install`** — попробуй ещё раз: закрой терминал, открой заново по шагу 2 и напиши `npm install` снова.
- **QR-код не сканируется** — телефон и компьютер должны быть подключены к **одной и той же** Wi-Fi сети.
- **Хочешь запустить в браузере вместо телефона** — после `npx expo start` нажми `w` в том же терминале. Откроется вкладка в браузере.
- **Остановить проект** — в терминале нажми `Ctrl + C`

## Короткий список для следующего раза

Когда захочешь запустить проект повторно:

1. Открыть терминал в папке `rndm_crew` (Shift + ПКМ → Открыть в Терминале)
2. `npx expo start`
3. Отсканировать QR-код в Expo Go
